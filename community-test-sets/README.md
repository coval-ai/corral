# Community test sets

Test sets brought by the community. To submit one, open a
[test set issue](https://github.com/coval-ai/corral/issues/new?template=submit-test-set.yml).

We review each submission. Accepted ones are added here as their own directory
and may be run on our public harness.

These are kept apart from `src/corral/scenarios/`, which holds the scenarios we
run ourselves.
